## 3. 判别原理描述

### 3.1 glm 的判别链（以置信度最高的 007 为例）

```
原始信号 → 去趋势 → Kurtogram 自适应选带（本次选 7000–8000 Hz，包络峭度 6.1）
  → 带通 → Hilbert 包络 → 包络谱
  → 对 4 个候选频率（BPFO/BPFI/BSF/FTF @ fr_est）逐个检索 1–5 次谐波
  → 每个谐波：在 k×fc ±max(2%, 1.5 根谱线) 窗内找峰，
    显著度 = 峰幅值 / 局部邻域（±16%）中位数
  → 命中需显著度 ≥5；单谐波贡献封顶；谐波权重 1/k；得分 ∈[0,1]
  → 判故障需 得分≥0.15 且 命中谐波数≥2，否则判"未检出"
  → 置信度 = 得分 ×(1 − 0.5×次高/最高)；另有整数倍混淆消歧（BPFO≈n×FTF 打折）
```

007（记录组"外圈4"，fr_est=19.27 Hz）的实际证据——**BPFI 谐波族三连命中，与理论频率偏差 <0.3%**：

| 谐波 | 理论频率 | 实测峰 | 局部突出度 |
|---|---|---|---|
| 1×BPFI | 85.22 Hz | 85.00 Hz | 25.9× |
| 2×BPFI | 170.44 Hz | 170.33 Hz | 18.9× |
| 3×BPFI | 255.66 Hz | 255.33 Hz | 14.0× |

即：包络谱中存在一族等间隔谱线，间隔精确等于内圈故障特征频率（阶次 4.4216×fr），每根高出局部背景一个数量级——**"重复冲击率 = BPFI"的内圈故障物理指纹**。BPFO/BSF/FTF 候选无此谐波族，故判内圈、置信 0.69。其余头部样本证据同构（012 五次谐波全命中、突出度 5–11×、选带包络峭度 22.1，属强冲击样本）。

### 3.2 kimi 的判别链（同样本 007）

```
带通（本轮注入 Kurtogram 选带）→ Hilbert 包络 → 包络谱（全带 0–8 kHz）
  → 对 4 类故障各检索 1–3 次谐波（±2% 容差）内最强峰
  → 得分 = 命中峰幅值 / 包络谱全局中位数 的调和平均
  → 判决 = argmax(得分)，且 max<15 才判 healthy（阈值 15 为仿真标定）
```

007 的 kimi 证据：同样三根峰 85.0/170.33/255.33 Hz，幅值与全局中位数之比 4757/3133/1775——**与 glm 命中的是同一组物理谱峰**，经不同基线（全局 vs 局部中位数）与不同聚合（调和平均 vs 加权得分）得出同一结论"内圈"。这正是第 1 节 88% 类型一致率的机理来源：两方案的分歧在门控（检出与否），不在定类。

### 3.3 两方案判别行为的本质差异

| 环节 | glm | kimi |
|---|---|---|
| 检出门控 | 双阈值（得分≥0.15 且谐波≥2）+ 保守出口 | 单一绝对阈值（15，仿真标定） |
| 本数据上门控行为 | 32.1% 检出，未检出即拒绝定类 | 门控失效，100% 检出 |
| 显著度基线 | 局部邻域中位数（抗谱形衰减） | 全局中位数（本数据上被 24 千根谱线稀释到 ~1e-6，比率爆炸） |
| 置信度语义 | [0,1] 概率化分数（含次高折扣） | 无概率；top 分量纲依赖数据，领先比是可用的确信度代理 |
| 定类一致性 | ——两方案在双检出样本上 88% 同类型—— | |

## 4. 数据集层面的解读（不依赖标签）

1. **两方案检出/高置信判决强烈集中于"内圈（BPFI）"特征**：glm B 轮 12/26、其置信度前十全部为内圈；kimi B 轮 34/81。若台架记录无误，这直接与主报告第 7 节的标签矛盾清单互证；即便不看标签，"全数据集最显著的重复冲击指纹是 BPFI 族"这一结论本身独立成立（007/008/003 等样本中 1–3 次谐波与理论频率偏差 <0.8%、突出度 5–27×，远超巧合水平）。
2. **次显著的指纹是 2×BSF（滚珠）**：kimi 高领先比的 044/043/080（2 次谐波分项比高达数千），glm 亦有 6 例滚珠检出（B 轮）。
3. **kimi 绝对分不具备跨样本可比性**：其 top 分前列（044 滚珠 4.2 万；081/080 内圈10 组 3.9/3.4 万；068/069 内圈4 组 2.8/2.6 万）集中在 fr_est 处于转速窗顶端的记录（19.9–20.0 Hz），分数随包络谱背景结构漂移——这正是本报告对 kimi 改用领先比排名的原因。且正常记录组的 030 也混入其绝对分前十（滚珠 1.3 万），门控失效的直接后果。
4. **55 条 glm 未检出的样本并非"确认健康"**：其中含 glm 自己标注"冲击成分弱"（包络峭度<4）的信号与频率错位样本；在转速未实测、部分样本证据不足的条件下，"未检出"是诚实的拒绝判决而非阴性结论。
