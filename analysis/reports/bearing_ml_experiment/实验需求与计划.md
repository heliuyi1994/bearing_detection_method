## 1. 需求说明

### 1.1 背景与目标

仓库已从音频资产库整理出三类原始音频数据集 `datasets/`（见 1.2）。本实验在其上做一次**轴承故障二分类的特征工程与模型效果评估**：

- 用 **normal + bearing** 两类数据做特征提取、模型训练与交叉验证评估；
- 用 **abnormal/others**（非轴承异常：摩擦/故障等）**只做工作点（阈值）标定**，即需求方所述"修正参数"；
- 目标：**bearing 召回率（recall）尽可能高**，others 上允许适度误报（≲30% 上限）；
- 特征工程复用统一包 `bearing_unified_method` 的现成特征与指标；
- 同时跑统一包 v2 DSP 诊断作为**零训练基线**对照，检验 ML 相对物理规则法的增益。

历史锚点（同源数据 audio-assets 1349 条，统一包验收报告 2026-09-23）：v2 DSP 轴承**全体口径（含未定位）检出 48.8%**（82/168）、正常误报 2.1%、转速自估回退率 92.6%（回退 1150 rpm）。DSP 基线结果应与该量级可对照。

### 2.2 新建脚本规格：`analysis/run_ml_bearing_experiment.py`

自包含（不 import run_eval_unified，公共小函数可直接复制），argparse 仅 `--smoke` 旗标。流程：

1. **加载数据**：读 `../datasets/manifest.csv`（UTF-8），跳过 `category=excluded`；按 `category` 分三子集；WAV 用 `read_wav_any` 同款实现（规格见 2.3-④）。`--smoke` 时三类各分层抽样 8 条。
2. **特征提取**：对 1261（或 smoke 子集）文件逐条 `extract_features(x, fs, use_physical=False, bearing="FIELD7")` → 36 维，特征名同步取 `feature_names(use_physical=False)`。**缓存**到输出目录 `features.npz`（含 X、文件名、类别；全量模式写入、重跑时命中即跳过；`--smoke` 不缓存）。非有限值替换为 0.0（包内同款做法）。
3. **监督模型 5 折 CV**：`StratifiedKFold(5, shuffle=True, random_state=42)`，y = 0(normal) / 1(bearing)，仅用 normal+bearing 的 735 样本。每折用 `make_estimator(name)` 重建未拟合估计器（zoo 定义已内含 StandardScaler 管线或树模型），`fit` 后收集 OOF 的 `predict_proba` 中 bearing 类概率（列下标用 `model.classes_` 定位）。四个模型名：`"LinearSVM"`, `"RBF-SVM"`, `"RandomForest"`, `"HistGB"`。
4. **novelty 后端同协议**：`make_estimator("novelty:elliptic_envelope", feature_names=<36维特征名列表>)`——它内部按 `feature_names` 自动定位 4 维冲击性子集（t1_kurtosis / t1_crest_factor / t1_clearance_factor / t5_env_peak_prom），`fit(X, y)` 只用 y==normal 样本（y 需用字符串标签 `"normal"/"abnormal"`，常量 `bearing_unified.ml.train.NORMAL/ABNORMAL`）。评分用其 `predict_proba`（伪概率，单调轴上可操作）同样做 5 折 OOF。
5. **模型选优与工作点**：
   - 按 OOF **AUC-PR**（average_precision）对 5 个模型排序；
   - 最优模型全量 refit → 对 **others 526 条**打分 → **标定阈值 = others 分数的 70 分位数**（对应 FPR≤30%）；
   - 报该阈值下（阈值套用到 CV-OOF 分数上）：bearing recall、normal 误报率、others 误报率（标定口径）；
   - 另报 recall@0.90 / 0.95 / 0.98 三档（由 OOF 分数分布反查阈值）对应的 normal 误报与 others 误报代价表。
6. **DSP 零训练基线**：对全部文件跑 `diagnose(x, fs, bearing="FIELD7", rpm_window=(1100.0, 1200.0))`（不传 rpm、不传 calibrator）。bearing 阳性两口径：**口径 A（仅定位）**= `verdict ∈ {BPFO, BPFI, BSF}`；**口径 B（主口径，含未定位，对应"盲梳检存在性"）**= 口径 A ∪ `verdict == "bearing_unlocalized"`（等价于净梳落入轴承路径）。对三子集分别报检出/误报，与 ML 最优工作点同表。注意：无 calibrator 时无梳样本判 normal（friction 判决不会出现），这是预期行为。
7. **特征重要性**：RandomForest 与 HistGB 全量 refit 后的 feature importances 取 top-15（两模型各一张表/图）。
8. **图**（`figures/*.png`，300 dpi）：① 5 模型 OOF P-R 曲线；② 阈值扫描曲线（x=阈值，双 y：bearing recall 与 others/normal 误报率，竖线标标定阈值）；③ 最优模型@标定阈值的三类混淆矩阵；④ DSP vs ML 检出对比柱状图；⑤ 特征重要性条形图。
9. **落盘产物**（目录 `analysis/reports/bearing_ml_experiment/`）：
   - `results.csv`：逐文件（1261 行）—— file_name, category, description, 各模型 OOF bearing 概率, 最优模型@标定阈值预测, DSP verdict 及两口径阳性标记, 特征提取/DSP 耗时, note；
   - `eval_detail.json`：口径声明（数据、决策 8 项、FIELD7+转速窗、标签声称值、others 标定口径、随机 5 折限制）、计数、每模型 OOF 指标（AUC-PR / recall / normal 误报 / others 标定误报）、标定阈值、工作点表、DSP 基线两口径指标、特征重要性、skipped、timing；
   - `实验报告.md`：中文 markdown，含**口径声明**与**诚实纪律**（指标不达预期就如实报告并归因，不粉饰）；结论须回答"ML 特征工程相对 v2 DSP 的增益是多少"。
