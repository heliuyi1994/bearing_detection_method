## 1. 引言：为什么用振动信号诊断轴承

滚动轴承是旋转机械中最常见、也最易损坏的部件之一。统计上，旋转机械故障中相当
比例源于轴承（各类文献引用的数字从 20% 到 45% 不等，取决于设备类型）。轴承从
出现早期微缺陷到完全失效通常有一个发展过程，这为**状态监测与预知维修**提供了
时间窗口——而振动信号是这个窗口里信息最丰富的观测手段：

- 局部缺陷产生的**冲击脉冲**直接调制在振动信号中，重复率由轴承几何与转速唯一
  决定，具有"指纹"性质（第 3 章）；
- 冲击激发结构共振，把微弱缺陷信号**放大**到一个易于测量的高频频带（第 7 章）；
- 传感器（加速度计）安装方便、成本低、不侵入设备。

### 传统信号处理方法与机器学习方法的定位

| | 传统信号处理（本库） | 机器学习/深度学习 |
|---|---|---|
| 原理 | 物理机理驱动：特征频率是几何与转速的确定函数 | 数据驱动：从样本中学习故障模式 |
| 需要的数据 | 一段信号 + 轴承几何参数（v2 规则不强依赖转速，见第 10–12 章） | 大量标注样本（每种工况、每种故障） |
| 可解释性 | 强：每一步有物理含义，可人工复核 | 弱：黑箱打分 |
| 泛化能力 | 不受工况/机型变化影响（换轴承参数即可） | 工况漂移时需重新训练 |
| 适用场景 | 少样本、多机型、需可解释的工业现场 | 数据充足、模式复杂的场景（变转速、多故障耦合） |

工程实践中的主流做法是**传统方法做特征提取与初判，人工或模型做最终裁决**。
本库（统一包）实现的是这条经典主线的 v2 形态：

```
预处理（去直流/去趋势/零相位带通） → 时域指标（是否有冲击？）
→ Kurtogram（冲击藏在哪个频带？） → 零相位解调 → 包络谱
→【盲梳检】观测峰梳扫 + 倒频谱互证（轴承故障特征存在吗？不依赖理论频率）
→【频带落入定位】故障在哪个部位（外圈/内圈/滚珠，3 类置信度）
→（可选）马氏健康基线辅助判据 / ML 两级模型 → 人工复核包络谱
```

与旧式"理论频率锚定匹配"（v1）的关键差别：v2 先不问"理论谱线在哪"，而是
先问"信号里有没有周期冲击族"（存在性），存在之后才用几何定位（部位）。
这一改动来自两批真实数据评测的三条教训（详见第 10–12 章与 design.md D14）：
转速先验不可靠（第二批现场数据转速自估回退率高达 92.6%）、健康总体的
冲击性特征重尾使马氏阈值触发级灵敏度塌陷、固定绝对阈值不可跨域迁移。

## 2. 滚动轴承结构与故障振动机理

### 2.1 结构与四个故障部位

滚动轴承由内圈（随轴旋转）、外圈（通常固定于轴承座）、滚动体（球或滚子）和
保持架（分隔滚动体）组成。四个部件对应四类典型单点故障：

| 部位 | 代号 | 振动特征 |
|---|---|---|
| 外圈 | **BPFO**（Ball Pass Frequency Outer） | 滚动体每次滚过外圈缺陷产生一次冲击；外圈相对载荷区固定，**冲击等幅** |
| 内圈 | **BPFI**（…Inner） | 内圈缺陷随轴旋转，周期性进出载荷区，冲击幅值被**转频 fr 调制**（幅值包络以 1×fr 起伏） |
| 滚动体 | **BSF**（Ball Spin Frequency） | 缺陷随滚动体自转撞击内外圈，且滚动体公转随保持架，幅值被 **FTF 调制**；缺陷每自转一周可能撞击两滚道，谱线常出现在 **2×BSF** |
| 保持架 | **FTF**（Fundamental Train Frequency，保持架频率） | 保持架碰擦外圈/滚动体，冲击**弱、频率低、滑移大** |

**统一包的判别类别为 3 类：外圈 BPFO / 内圈 BPFI / 滚珠 BSF**（滚珠 2×BSF
主峰带归入滚珠）。保持架 FTF 的特征频率计算能力保留（`fault_freqs.py`、
`matcher.py` 的整数倍消歧），但**不参与判别**——依据是真实台架评测中
保持架谱线弱且与 BPFO 存在恒等混淆（9.4 节/11 章），强行判别弊大于利
（design.md D21）。

### 2.2 从缺陷到振动的物理链条：冲击 → 共振 → 调制

单点缺陷的振动机理可以用一条清晰的因果链描述：

1. **冲击脉冲**：滚动体压过缺陷边缘的瞬间，接触力突变，产生一个宽度极窄
   （微秒级）、能量集中在宽频带的**冲击力脉冲**，近似狄拉克函数 δ(t−tᵢ)；
2. **共振放大**：冲击激起轴承座—传感器系统的固有共振（典型几 kHz 到几十
   kHz）。若共振频率 f_r、阻尼比 ζ，冲击后的自由衰减振动为：

   $$h(t) = e^{-2\pi \zeta f_r t}\sin(2\pi f_r t),\qquad t\ge 0$$

   其时间常数 τ = 1/(2πζf_r)——ζ≈0.08、f_r=3 kHz 时 τ≈0.66 ms，即每次冲击
   留下一段几毫秒的高频衰减振荡；
3. **重复与调制**：缺陷被滚过一次产生一次冲击，冲击时刻 tᵢ 以特征频率 f_c
   到达（含 1~2% 随机滑移），于是振动信号近似为**冲击串与共振核的卷积**：

   $$x(t) \approx \sum_i A_i\, h(t-t_i) + n(t),\qquad t_i \approx i/f_c$$

   内圈的 Aᵢ 随 1×fr 起伏（进出载荷区），滚动体的 Aᵢ 随 FTF 起伏。

### 2.3 这个模型决定了诊断方法的形态

关键观察：故障信息**不在共振频率本身**（那是结构的属性，不是故障的属性），
而在共振振荡的**重复率与幅值调制**里——即高频载波上的低频包络。这就是第 7
章包络解调的物理出发点：解调把"高频载波上的低频信息"搬运到可以直接读谱的
低频段。`simulate.py` 实现的正是上述冲击串模型，用于在无真实数据时生成带
已知答案的测试信号。

**对 v2 的直接启示**：既然故障的本质证据是"包络中的周期结构"，那么检测它
原则上**不需要先知道周期是多少**——先在包络谱上盲检周期族（第 10 章梳检），
再用几何去认领周期（第 11 章定位）。v1 的次序（先理论后验证）把转速先验变
成了单点依赖；v2 把它降级为定位阶段的软约束。

## 3. 故障特征频率及其几何推导

设轴承节圆直径（滚动体中心所在圆）为 D，滚动体直径 d，滚动体数 n，接触角 α，
轴转频 fr (Hz)。以下推导假设纯滚动（接触点无滑动）。

### 3.1 保持架频率 FTF

外圈固定、内圈以 fr 旋转。内圈滚道表面在接触点处的线速度：

$$v_i = \pi(D - d\cos\alpha)\, f_r$$

外圈接触点线速度 v_o = 0。滚动体在两滚道间纯滚动，其**中心速度**是两接触点
速度的平均值：

$$v_c = \frac{v_i + v_o}{2} = \frac{\pi(D - d\cos\alpha) f_r}{2}$$

保持架与滚动体中心一起公转，绕行一周的路程为 πD：

$$\boxed{\;\mathrm{FTF} = \frac{v_c}{\pi D} = \frac{f_r}{2}\left(1 - \frac{d\cos\alpha}{D}\right)\;}$$

### 3.2 外圈故障频率 BPFO

外圈固定，缺陷在载荷区不动；滚动体（连同保持架）每公转一周经过外圈滚道某
固定点 n 次。单位时间经过缺陷的滚动体数 = n × 保持架相对外圈的转速 = n·FTF：

$$\boxed{\;\mathrm{BPFO} = \frac{n}{2} f_r \left(1 - \frac{d\cos\alpha}{D}\right) = n\cdot\mathrm{FTF}\;}$$

**BPFO = n×FTF 是恒等关系**（与 `matcher.py` 的整数倍消歧逻辑直接相关，
该模块在统一包中服务于 v2 的理论复核步骤，见第 11 章）。

### 3.3 内圈故障频率 BPFI

内圈以 fr 旋转，保持架以 FTF 公转，内圈缺陷相对滚动体系的转速为 fr − FTF；
每公转一周有 n 个滚动体经过缺陷：

$$\mathrm{BPFI} = n(f_r - \mathrm{FTF}) = \frac{n}{2} f_r \left(1 + \frac{d\cos\alpha}{D}\right)$$

### 3.4 滚动体自转频率 BSF

滚动体在外圈接触点纯滚动：滚动体表面相对其中心的速度等于接触点相对滚动体
中心的速度 v_c，故自转角频率 ω_b = v_c/(d/2)：

$$\mathrm{BSF} = \frac{\omega_b}{2\pi} = \frac{D}{2d}\, f_r\left(1 - \left(\tfrac{d\cos\alpha}{D}\right)^2\right)$$

注意：滚动体上的一点每自转一周分别与内、外滚道接触各一次，故**缺陷冲击的实
际重复率常为 2×BSF**；工程上也常直接以 BSF 及其谐波为诊断依据。统一包的两条
路径都覆盖这一形态：盲梳检的下探规则会把 2×BSF 强的梳归并到 BSF 基频
（第 10.3 节），频带表中滚珠类同时有 BSF 基频带与 2×BSF 主峰带（第 11.1 节）。

### 3.5 滑移的影响

实际轴承存在打滑（滚动体与滚道间的微小滑动），使实际特征频率比理论值低
1%~3%，且每次冲击间隔有随机抖动。后果是：

- 实测谱峰位置略低于理论频率（谐波搜索窗默认 ±2%，理论复核放宽为 ±4%，
  见 11.3 节）；
- 高次谐波被"抖模糊"（相位失配使高次谐波幅值下降），因此匹配权重取 w_k=1/k，
  低次谐波更可信。

### 3.6 验证：CWRU 公布值与现场台架

以 CWRU 数据集的驱动端轴承 SKF 6205-2RS JEM（n=9, D=39.04 mm, d=7.94 mm,
α=0°）在 1797 rpm（fr=29.95 Hz）为例，d/D=0.2034：

| 频率 | 公式计算值 | CWRU 公布值 |
|---|---|---|
| FTF | 11.93 Hz | 11.92 Hz |
| BSF | 70.58 Hz | 70.59 Hz |
| BPFO（=9×FTF） | 107.36 Hz | 107.36 Hz |
| BPFI | 162.19 Hz | 162.19 Hz |

（`tests/test_fault_freqs.py` 逐项断言了这组对照。）

统一包另内置现场台架轴承 **FIELD7**（n=7, D=15.0 mm, d=3.969 mm, α=5.6°，
外圈固定内圈随轴；由 `labeled_dataset_4class/geometry.json` 注册），阶次
（×fr）：BPFO 2.578320 / BPFI 4.421680 / BSF 1.758605 / 2×BSF 3.517209 /
FTF 0.368331，满足恒等式 BPFO + BPFI = n·fr（tests 中有断言）。

## 4. 时域统计指标

时域指标计算代价极低，是监测系统的第一道哨兵。对零均值信号 x（长度 N），
本库计算 9 项无量纲/有量纲指标（`indicators.py`）：

### 4.1 定义

| 指标 | 定义式 | 物理意义 |
|---|---|---|
| 均方根 RMS | $\sqrt{\frac{1}{N}\sum x_i^2}$ | 振动总体能量，反映磨损等渐变劣化 |
| 峰值 Peak | $\max\lVert x_i\rVert$ | 最大瞬时幅度 |
| 峰峰值 P2P | $\max x_i - \min x_i$ | 摆动范围 |
| 峭度 Kurtosis | $\frac{E[x^4]}{E[x^2]^2}$ | 分布尖锐程度：正态=3，冲击型信号>3，正弦=1.5 |
| 偏度 Skewness | $\frac{E[x^3]}{E[x^2]^{3/2}}$ | 分布不对称性，对单侧冲击敏感 |
| 峰值因子 Crest | $\frac{\text{Peak}}{\text{RMS}}$ | 冲击性（正弦=√2≈1.41，冲击>2） |
| 脉冲因子 Impulse | $\frac{\text{Peak}}{\frac{1}{N}\sum\lVert x_i\rVert}$ | 比峰值因子对冲击更敏感 |
| 波形因子 Shape | $\frac{\text{RMS}}{\frac{1}{N}\sum\lVert x_i\rVert}$ | 波形形状（正弦≈1.11） |
| 裕度因子 Clearance | $\frac{\text{Peak}}{\left(\frac{1}{N}\sum\sqrt{\lVert x_i\rVert}\right)^2}$ | 对早期点蚀冲击最敏感的指标族 |

其中分母含均值的三个因子（脉冲/波形/裕度）依赖"信号均值的绝对量"，峭度、
峰值因子等无量纲指标则不随载荷/增益整体缩放而变，适合做趋势监测。

### 4.2 为什么峭度是"早期故障第一指标"

峭度度量的是分布的尾部重量。健康轴承的振动近似高斯（峭度≈3）；出现局部缺陷
后，稀疏强冲击让分布出现重尾，峭度显著升高（可达 10~20+）。它的价值在于：
**对冲击的存在性敏感，但对冲击来自哪个部位无分辨力**——峭度升高只说明"有冲
击"，不能说明"外圈还是内圈"，这正是后续频谱分析要回答的问题。

### 4.3 局限

- 磨损类分布式故障（无离散冲击）峭度几乎不变，RMS 更合适；
- 强背景干扰（齿轮啮合、电磁 50 Hz）会抬高所有指标；
- 峭度随故障发展先升后降（严重时冲击连成片，分布重新"均匀化"），因此
  峭度正常 ≠ 轴承健康——只能作为辅助证据，最终裁决靠包络谱结构分析
  （第 7、10 章）；
- **健康总体的冲击性指标可能重尾**：第二批现场数据（1349 条）实测正常集
  峭度 p99≈332、最大 902——健康录音里也常见强瞬态（详见 baseline.py 的
  "重尾塌陷"记录）。这直接限制了"以冲击性指标做门控"的可用阈值形态，
  是 v2 把存在性判决交给梳检（周期结构）而非冲击强度（幅度）的重要原因。

## 5. 频域分析：FFT 频谱

### 5.1 DFT 与幅值谱

离散傅里叶变换把 N 点信号分解为谐波分量：

$$X(k) = \sum_{i=0}^{N-1} x_i\, e^{-j2\pi ki/N},\qquad k=0,\dots,N/2$$

单边幅值谱取 |X(k)| 并乘 2/N（本库用窗函数时乘 2/Σw 做增益校正）。频率分辨率：

$$\Delta f = \frac{f_s}{N} = \frac{1}{T}$$

只取决于采集时长 T——这是"判 FTF（约 10 Hz 量级）需要至少几秒数据"的原因。

### 5.2 窗函数与频谱泄漏

对信号做 DFT 隐含周期延拓，直接截断（矩形窗）会造成频谱泄漏：单频信号的能
量泄漏到相邻频带，掩盖附近弱谱线。本库的 `amplitude_spectrum` 加**汉宁窗**
（Hann），其主瓣宽（±2 根谱线）但旁瓣低（−31 dB），适合读取离散谱线。

### 5.3 轴承故障在"裸"频谱里长什么样

直接对振动信号做 FFT，通常看到的是：

- 转频 fr 及其低次谐波（不平衡、不对中）；
- 结构共振区的一片"山丘"——故障冲击的能量散布在共振频带内，**看不到离散的
  特征频率谱线**；
- 谐波峰两侧的**边带**族（间隔为调制频率）。

也就是说：**故障特征频率在原始频谱上是"藏"在共振频带的边带结构里的**。
把边带族挑明有两条路：包络解调（第 7 章，主力）与倒频谱（第 9 章，辅助）。
而"原始谱 + 包络谱"读取的前提是干净的预处理——下一章。

## 6. 预处理与零相位滤波

预处理位于流水线最前端（`preprocessing.py`，移植自 kimi 方案，替代 glm
散落的非零相位处理），三步：去直流、去线性趋势、（按需）零相位带通。

### 6.1 去直流与去趋势

- `remove_dc`：减去均值。直流分量通常来自传感器偏置与采集链路零点漂移，
  与故障无关，却会在频谱零频附近形成"能量山"并污染低频窗；
- `detrend`：去除线性趋势（`scipy.signal.detrend`）。慢变趋势（热漂移、
  安装沉降）会弯曲谱的低频端，让包络谱的低频窗基线失真。

### 6.2 为什么要零相位：`sosfilt` vs `sosfiltfilt`

带通滤波是包络解调的前置步骤。普通 IIR 滤波（`sosfilt` 前向一次）有两个
代价：

1. **相位畸变**：滤波器的非线性相位使不同频率成分产生不同群延迟——冲击
   的"到达时刻"在时域上被拉开，包络的峰位与形状失真；
2. **起始瞬态**：滤波器冲激响应的振铃会虚增包络峭度，误导 Kurtogram 选带。

`sosfiltfilt`（前向-反向各滤一遍）把相位响应精确抵消为零：

$$Y(f) = X(f)\,|H(f)|^2,\qquad \angle Y(f) = \angle X(f)$$

代价是幅值响应变为 |H|²（阻带衰减翻倍、通带仍近似无损）与两倍计算量。
对轴承诊断，**冲击时刻不偏移**比阻带多几十 dB 衰减更重要——包络的时域
定位、梳检的峰位一致性、倒频谱的 q 值精度全部受益。统一包所有解调带通
（`diagnose.py`、`ml/features.py`）一律用 4 阶 Butterworth `sosfiltfilt`。

工程细节：Kurtogram 可能选出贴奈奎斯特或贴 0 的候选频带（如 (0,500) 或
(7500,8000)@16 kHz），`preprocessing.clamp_band` 先把频带夹取到合法域
0 < low < high < fs/2 再滤波，避免滤波器设计非法。

### 6.3 两条预处理路径的分工

统一包内部有两条预处理路径，职责不同：

- **轻预处理**（去直流+去趋势，不带通）：供 Kurtogram 选带与包络解调。
  选带必须在"全频带都有真实内容"的信号上进行——若先宽带带通，带外只剩
  滤波器残差，其包络峭度是尺度不变的数值尘埃，可能虚假胜出（合并原型
  开发期实测）；
- **宽带预处理**（去直流+去趋势+零相位带通 (500, min(7500, 0.47·fs)) Hz，
  16 kHz 台架口径）：供转速自估的包络谱与触发级时域特征。下沿 500 Hz
  去除低频轰隆与工频（远高于本台架最高特征频率 BPFI≈88 Hz），上沿
  7500 Hz 给奈奎斯特留余量；能量集中的 1.5–3 kHz 主共振区完整保留。

## 7. 包络解调分析（共振解调法）

包络解调（Envelope Analysis，工程上常称共振解调/冲击脉冲法）是轴承诊断公
认最有效的单一方法。

### 7.1 调制模型回顾

由第 2 章模型，故障信号是冲击串卷积共振核：

$$x(t) = \sum_i A_i\,h(t-t_i) + n(t)$$

若冲击严格周期（间隔 T_c=1/f_c）且等幅，可写成傅里叶级数形式的**幅值调制**：

$$x(t) \approx \left[\frac{A_0}{2} + \sum_m A_m\cos(2\pi m f_c t)\right]\cdot c(t)$$

其中 c(t) 是共振频带内的载波。即：**高频载波的包络以故障特征频率 f_c（及其
谐波）起伏**。

### 7.2 Hilbert 变换与解析信号

Hilbert 变换把信号的每个频率分量移相 −90°：

$$\mathcal{H}\{x\}(t) = \frac{1}{\pi}\,\mathrm{p.v.}\!\int_{-\infty}^{\infty}\frac{x(\tau)}{t-\tau}\,d\tau,
\qquad \mathcal{H}\{\cos\omega t\}=\sin\omega t$$

构造解析信号：

$$x_a(t) = x(t) + j\,\mathcal{H}\{x\}(t) = a(t)\,e^{j\phi(t)}$$

对窄带信号，a(t)=|x_a(t)| 正是**包络**——载波被剥离，只剩下低频的幅值起伏。
对 x_a 做傅里叶分析的谱称为**包络谱**（`spectrum.envelope_spectrum`）：

$$\text{包络谱} = \left|\mathrm{FFT}\left[\,|x_a(t)| - \overline{|x_a|}\,\right]\right|$$

（去均值消除直流；`envelope_spectrum` 支持 `max_freq` 截断输出窗口，
统一包 v2 取 0–800 Hz 以覆盖 150 Hz 基频的 5 次谐波。）

### 7.3 为什么必须先带通

对原始信号直接取包络效果很差，原因有三：

1. 原始信号含大量与故障无关的低频成分（转频谐波、齿轮啮合），其幅值同样进
   入包络，淹没特征谱线；
2. 冲击能量分布在所有共振频带，包络谱上各带的调制互相混叠；
3. 多共振带叠加使包络起伏失真。

**带通滤波把一个共振频带孤立出来**，相当于选定了"载波"，包络解调才能干净
地恢复调制信息。带通的中心怎么选？——手工试探既慢又依赖经验，这正是第 8 章
Kurtogram 要自动解决的问题。统一包的带通一律零相位（第 6 章）。

### 7.4 包络谱的判读要点

- **离散谱线出现在 f_c、2f_c、3f_c…**：谐波族是"滚动体反复滚过同一缺陷"的
  指纹；只看一根谱线不可靠（干扰也会造一根线），**看谐波族**——这是 v2
  盲梳检的直接理论依据（第 10 章）；
- 内圈故障：f_c 谱线周围出现 ±fr 间隔的**边带**（载荷区调制）；
- 滚动体故障：出现 ±FTF 边带，且 2×BSF 常比 1×BSF 强；
- 转速波动与滑移会加宽谱线、压低高次谐波。

## 8. 谱峭度与 Kurtogram：自适应频带选择

### 8.1 谱峭度的定义与直觉

峭度度量冲击性（第 4 章），但它是对**整段信号**算的一个数。把它推广为
**频率的函数**，就是谱峭度（Spectral Kurtosis, SK）：

$$\mathrm{SK}(f) = \frac{\langle |X(t,f)|^4\rangle_t}{\langle |X(t,f)|^2\rangle_t^2} - 2
\quad\text{（Wold–Cochran 估计，减 2 修正平稳高斯基线）}$$

其中 X(t,f) 是信号的短时傅里叶变换，⟨·⟩ 为时间平均。直觉：

- 平稳高斯过程：任何频率分量的幅值分布都接近瑞利/高斯，SK≈0（修正后）；
- **瞬态冲击**：激发共振带的能量随时间剧烈起伏，该频带的 SK 显著为正。

即 SK(f) 指出"**哪个频带最富含瞬态成分**"——正是包络解调想要的载波频带。

### 8.2 带内包络峭度：SK 的带内积分等价形式

工程实现（`kurtogram.py`）不显式算 SK(f)，而是对候选频带 B=[f_l, f_h] 带通
后计算**包络峭度**：

$$K_B = \frac{\langle e_B^4(t)\rangle}{\langle e_B^2(t)\rangle^2},\qquad e_B=|\,\text{analytic}(x_B)\,|$$

K_B 与该带 SK 的积分统计量单调对应：带内冲击越突出，包络起伏越大，K_B 越高。
窄带高斯噪声的包络服从瑞利分布，未中心化 4 阶矩比基线为 **2.0**（注意：不
是原始高斯信号的 3.0——实现与测试均以 2.0 为噪声基线）。

### 8.3 Kurtogram：树状频带搜索

Antoni（2006）的快速 Kurtogram 把频带搜索组织成一棵树：

- 第 1 层把 [0, fs/2) 二分为 2 个频带；
- 第 j 层分出 2^j 个二进制频带，**并附加同层错位 1/3 倍频程频带**（宽度
  2/3·带宽、起点步进 1/3 带宽），使频带边界的划分更灵活；
- 每个频带计算 K_B，取全树最大者为解调频带。

本库用 butter 带通（sos 级联，数值稳定）+ Hilbert 包络峭度直接实现这棵树，
默认 4 层（最窄频带 fs/32），并做两个工程修正：

1. **剔除滤波瞬态**：带通滤波器起始振铃会虚增峭度，按 8·fs/B 截去头部；
2. **剔除端部伪影**：Hilbert 是 FFT 圆卷积实现，信号两端有回绕伪影，包络
   统计裁掉两端各 1%。

### 8.4 选带结果的用法与读法

Kurtogram 输出 (best_band, best_kurtosis)。best_kurtosis 本身也是证据：
≈2 说明该带与窄带噪声无异（信号里没有显著冲击），诊断报告会把这一点写进提
示（`diagnose.py` 中 best_kurtosis<4 触发"冲击成分弱"提示）。选中频带经
`preprocessing.clamp_band` 夹取后，用于第 6、7 章的零相位带通+包络解调。

## 9. 倒频谱分析

### 9.1 定义

实倒频谱（real cepstrum）是**对数功率谱的谱**：

$$c(q) = \left|\,\mathrm{IDFT}\{\log |X(k)|\}\,\right|$$

自变量 q 称为**倒频 (quefrency)**，量纲是时间（秒）。注意定义必须在谱具有
连续底噪时才有意义（纯离散线谱的 log 会退化，见测试注释）。

### 9.2 为什么能检测边带族

若频谱中存在间隔为 Δf 的边带族（如 BPFI±fr 的族、齿轮啮合频率的边带），
则 log|X| 中出现周期为 Δf 的纹波；对其再做谱分析，纹波凝聚为 q=1/Δf 处的
单峰，且其整数倍处出现"倒谐波 (rahmonic)"。

**等价视角**：倒频谱把"多根间隔均匀的谱线组成的族"压缩成"一根峰"，与包
络谱把"边带结构"解调成"谱线"是同一件事的两种实现。对边带间隔不均匀或
边带族很多（多故障源）的场景，倒频谱比肉眼读谱更省力。

### 9.3 在本库中的定位：梳检的第二证人

`real_cepstrum` 在统一包中升级为 v2 盲梳检的**互证环节**（`combdet.
cepstrum_confirm`，详见第 10 章）：谱域梳扫（A）发现的每个候选基频 f0，
必须在倒频域 q≈m/f0（m=1..3）处找到显著 quefrency 峰（局部邻域中位数
基线，显著度阈值与谱峰一致）才算确认——谱峰可能偶然成族，倒频域的独立
视角能把偶合率压一个量级。倒频谱同时仍作为人工复核的辅助证据进诊断结果
（`DiagnosisResult.cepstrum_*`）。

## 10. 盲梳检：不依赖理论频率的存在性确认

本章是 v2 相对 v1 的核心新增（`combdet.py`）。回答的问题：**信号里有没有
"轴承故障式"的周期冲击结构？**——在不知道转速、不知道理论特征频率的前提下。

### 10.1 动机：为什么把存在性与定位解耦

v1 的做法是理论锚定：给定转速与几何 → 算理论特征频率 → 在包络谱上逐个验证
谐波族。三个结构性问题在真实数据上逐一暴露（详见 design.md D14）：

1. **转速先验不可靠**：现场没有转速计，包络谱 1×fr 峰自估在第二批 1349 条
   现场录音上回退率高达 92.6%（prominence 不足，电机音主导）——理论锚定的
   频率基准大面积缺失；
2. **门控阈值不可跨域**：v1 触发级（马氏距离 p99）在健康总体冲击性特征重尾
   时灵敏度塌陷（第 4.3 节），异常检出率被压到 9.3%；
3. **轴承梳与轴频梳/工频梳混淆**：理论匹配器会把转频谐波族、50 Hz 工频族
   当成 BPFO 证据。

v2 的对策：**先在包络谱上盲检"周期族是否存在"（A 谱域梳扫 + B 倒频域互证
+ 干扰防护），存在之后才用几何去定位**（第 11 章）。存在性判断只用信号的
结构信息，不依赖任何先验频率。

### 10.2 A：观测峰驱动的梳扫

1. **显著峰拾取**（`pick_salient_peaks`）：在包络谱 [20,150] Hz 内取局部
   极大值，以"峰幅值/局部邻域（±max(16%, 10 谱线)）中位数 ≥ 5"为显著度
   ——与 matcher 的局部基线同一定义（抗包络谱 1/f 衰减形态）；
2. **候选基频**：每个显著峰都是候选基频 f0；
3. **谐波族验证**（`comb_match`，直接调 `match_fault_frequencies` 单候选）：
   在 k·f0（k=2..5）±max(2%, 1.5 谱线) 窗内找峰，命中要求局部突出度 ≥5；
   得分沿用 w_k=1/k 加权、突出度封顶 20 的公式；**确认条件：命中数 ≥2 且
   得分 ≥0.15**（沿用 glm 的判据参数）；
4. **下探最小基频**：若 f0/2 的谐波族命中数不少于 f0，就下探到 f0/2
   （最多 f0/16、下限为标称轴频窗下沿减 2 Hz）。理由：真实基频可能弱、
   其偶次谐波强（滚珠 2×BSF 主峰、偶阶调制），"能解释最多显著峰的最小
   基频"才是物理基频；下探结果落到 20 Hz 以下的梳是轴频族（转速量级），
   打 `low_f0` 标记按干扰排除；
5. **同族去重**：已接受梳的命中峰与其全部谐波上的显著峰不再作为新梳候选
   ——同一族峰只保留一个梳。

### 10.3 B：倒频谱互证

对每个 A 确认的梳 f0，在倒频谱上检查 q≈m/f0（m=1..3，覆盖基倒频与其
rahmonics）处是否有显著峰（局部中位基线、突出度 ≥5）。任一 rahmonic 显著
即互证成立。意义：谱域的"均匀间隔族"可能由几根不相干强峰偶然拼成，而
倒频域把周期凝聚为单峰，是独立的证据通道——两条通道同时成立才认"梳存在"。

### 10.4 干扰防护

确认存在的梳并非都是轴承故障。两类已知误报源（`mark_interference` +
`low_f0`）被显式排除（仍记录，报告统计命中数）：

- **轴频谐波族**：f0 ≈ k×fr_nominal（k≥1，fr_nominal 取标称转速窗中点，
  如 1150 rpm → 19.167 Hz）在 1.5 谱线内吻合；下探后 f0 < 20 Hz 的梳
  （low_f0）同样是轴频族兜底——实测 17.1 Hz 轴频谐波族的子梳 34.2/51.3 Hz
  若无此防护会分别落入滚珠/外圈频带造成假定位；
- **工频 50 Hz**：恰落在外圈频带 47.3–51.6 Hz 内，是经典误报源。容差取
  min(1.5 谱线, 0.4 Hz)——工频是精确频率，容差只覆盖谱分辨率；裸 1.5 谱线
  在短窗（ML 的 1–2 s 窗，df=0.5–1 Hz）下会形成 ±0.75–1.5 Hz 的宽区，
  把真外圈梳（49.42 Hz）误吞，故设 0.4 Hz 硬上限（design.md D15；
  49.42 Hz 距 50 Hz 0.58 Hz 安全，50.2 Hz 处的真外圈会被误标——固有歧义
  按建议稿取保守）。

### 10.5 实现期的两条教训（设计已固化，勿回退）

1. **同族吸收容差用 ±1% 而非 matcher 的 ±2%**（`combdet.ABSORB_TOL_REL`）：
   matcher 的 ±2% 搜索窗含滑差裕量，直接用于"同族吸收"会把相邻 ~2% 的
   **异族**强峰误并——实测中伪梳 33.08 Hz 曾把真梳 162.3 Hz（BPFI）当
   "5 次谐波"吸收，真故障漏检。同族判定收紧到 ±1%（≈滑差量级）：真族分裂
   的代价仅是产生一个同类的重复梳（良性），异族误并的代价是真梳被漏检
   （有害）——取前者；
2. **梳确认要求最低命中谐波 ≤2**（防"高次窗扫峰"伪梳）：错误基频的高次
   谐波窗（±2% 相对窗随 k 线性展宽）会扫到不相干强峰拼成假族。要求最低
   命中 k ≤ 2（基频或 2 次）后，伪梳被拒、真族不受影响——真族的基频或
   2 次谐波几乎总是命中的。

### 10.6 输出语义

盲梳检的输出是三态的：**无梳**（无轴承故障特征）、**有梳（净）**（存在，
进入第 11 章定位）、**有梳但被干扰排除**（记录不计入存在）。v2 判决中，
"无梳"才轮到马氏健康基线辅助判据（`baseline.py`）区分"异常-非轴承(摩擦)"
与"正常"——梳检是主检，马氏是兜底，门控的重尾塌陷问题（第 4.3 节）由此
被绕开。

## 11. 频带落入定位与理论复核

盲梳检确认"存在轴承故障特征"之后，第二个问题是"**故障在哪个部位**"
（`localize.py`）。统一包的定位只用外圈/内圈/滚珠三类，且**不用真实转速**：
频带由标称转速窗×几何预先推出，转速本身降级为软约束。

### 11.1 频带表：转速窗 × 几何的导出量

在标称转速窗（默认 1100–1200 rpm ↔ fr ∈ [18.33, 20.0] Hz）内，三类故障的
特征频率（含滚珠 2×BSF 主峰）占据四个**互不重叠**的频带——这是定位能做成
"查表"的前提。以 FIELD7（阶次 BPFO 2.578320 / BPFI 4.421680 / BSF 1.758605）
为例：

| 频带 | 类别 | 范围 (Hz) |
|---|---|---|
| BSF 基频带 | 滚珠 | 32.2 – 35.2 |
| BPFO 带 | 外圈 | 47.3 – 51.6 |
| 2×BSF 主峰带 | 滚珠 | 64.5 – 70.3 |
| BPFI 带 | 内圈 | 81.1 – 88.4 |

**频带是函数化的导出量**（`localize.class_bands(bearing, rpm_window)`），
不是硬编码表：换几何或换转速窗，频带随之重算（`bearing-unified bands`
子命令可直接打印；`tests/test_localize.py` 核对了默认窗数值与 900–1000
rpm 窗的重算）。工频 50 Hz 恰落在外圈带内——这是第 10.4 节工频防护必须
存在的原因；轴频整数倍 [k·fr]（k=2..7）恰好全部落在频带间空档
（36.7–40 / 55–60 / 73.3–80 / 91.7–100 / 110–120 / 128.3–140 Hz），这是
"故障频带互不重叠"设计的对偶红利：真轴频梳天然不抢故障频带。

### 11.2 落入与粗定类

梳基频 f0 落入某频带 → 粗定类为该带对应类别（滚珠两带同属滚珠）。
落入即等价于"存在窗内 fr_hyp = f0/(k·阶次)"，故**落入带内的梳不需要
真实转速即可归属类别**——转速先验的降级由此完成（对比 v1：转速错 2%
则理论频率全错位）。

### 11.3 理论复核与 ±4% 容差

粗定类必须经理论复核（防"巧合落带"）：

1. 对假设 (类, k)：fr_hyp = f0/(k·阶次) 夹取到轴频窗；
2. **准入**：理论频率 F = k·阶次·fr_hyp 与 f0 的偏差 ≤ **±4%**——比谐波
   搜索窗的 ±2% 放宽一档，用于覆盖"真实转速略出窗"的现场情形（实测
   fr≈17.97 Hz 的外圈故障 46.32 Hz 即靠此纳入窗边界；design.md D17）；
3. **吻合度打分**：以 fr_hyp 的三类理论频率跑 `match_fault_frequencies`
   （谐波搜索窗同样放宽 ±4% 参数化），取指定类得分，即该梳对该类的
   **置信度**（[0,1]，不归一）。

**空档补救路径**：f0 落在频带间空档时，对 (类, k=1..5) 逐个尝试
fr_hyp = f0/(k·阶次) 回窗 + 理论谐波族吻合（如 98.8 Hz = 2×BPFO，
k=2 回窗 → 外圈）；仍无解 → 判「**轴承特征存在但无法定位**」
（`bearing_unlocalized`），**单列统计、不强行归类**——空档梳多来自
出窗转速、非轴承周期源（实测中的 ~21 Hz 源、45 Hz 源），诚实标注比
强猜部位更有工程价值。

### 11.4 三类置信度合成

多梳共存时（实测常见），文件级置信度逐类取 max：

$$\mathrm{conf}_{c} = \max_{\text{梳 } j}\; \mathrm{score}_{c}^{(j)},\qquad c\in\{\text{外圈},\text{内圈},\text{滚珠}\}$$

argmax 即判定部位；定位成功的梳还会反演出 fr_hyp（窗内轴频估计，
诊断文本报告会打印——这是"转速自估"的副产品形态，比包络谱 1×fr 峰法
在故障文件上更可靠）。置信度不归一、不做 softmax：它是"该类证据有多强"
的独立量纲，跨文件可比（沿用 glm matcher 的得分语义）。

### 11.5 与 v1 理论锚定的行为对照

| 方面 | v1（理论锚定） | v2（盲梳检 + 频带落入） |
|---|---|---|
| 转速依赖 | 必需（错 2% 即失配） | 不需要（fr_hyp 从梳反演） |
| 存在性判据 | 理论谱线命中即存在（易误报） | 梳 A+B 互证（存在性独立于几何） |
| 无法解释时 | 判"normal"（漏报不可见） | 判"未定位"（诚实单列，可人工复听） |
| 干扰（轴频/工频） | 无防护，易误判外圈 | 显式标记排除并统计 |

## 12. 完整工作流、参数速查与局限

### 12.1 诊断决策树（v2）

```
拿到信号 x, 采样率 fs, 轴承参数（FIELD7 或内置库）
│
├─ 1. 预处理：去直流 + 去趋势               [preprocessing]
├─ 2. 宽带零相位带通 → 时域指标 + 转速自估（仅记录）  [preprocessing / diagnose]
├─ 3. Kurtogram 选解调频带 → 零相位解调 → 包络谱      [kurtogram / spectrum]
│     best_kurtosis ≈ 2 → 无显著冲击，倾向正常
├─ 4.【盲梳检】显著峰 → 梳扫 → 倒频谱互证 → 干扰防护   [combdet]
│     无净梳 → 转 6；有净梳 → 5
├─ 5.【定位】频带落入/补救 → 理论复核(±4%) → 3 类置信度  [localize]
│     定位成功 → 判部位；失败 → 判「轴承-未定位」
├─ 6.（可选）马氏健康基线辅助判据：无梳且距离越限 → 摩擦  [baseline]
└─ 7. 输出报告（四联图 + 文本 + JSON）→ 人工复核包络谱   [report]
```

### 12.2 参数速查

| 参数 | 默认 | 说明 |
|---|---|---|
| 采集时长 T | ≥2 s（建议 3 s+） | Δf=1/T；低频梳（20 Hz 量级）需 Δf≪20 Hz |
| 采样率 fs | ≥2×最高共振频率 | 一般 10~50 kHz 加速度计；本台架 16 kHz |
| Kurtogram 层数 | 4 | 最窄频带 fs/32；共振更窄可加到 5 |
| 梳候选基频范围 | [20, 150] Hz | 覆盖四类特征频带及其低次谐波归属 |
| 谐波数 K | 5 | 高次谐波受滑移模糊，一般不超过 5 |
| 谐波搜索容差 | ±2%（梳检）/ ±4%（理论复核） | 滑移 1~2% / 转速出窗裕量 |
| 峰显著度阈值 | 5 | 谱线高出局部邻域 5 倍才计命中 |
| 梳确认 | hits≥2 且 score≥0.15 且最低命中 k≤2 | 见 10.2/10.5 |
| 倒谱互证 | m=1..3 rahmonics，显著度 ≥5 | 任一显著即互证成立 |
| 工频防护容差 | min(1.5 谱线, 0.4 Hz) | 见 10.4 |
| 带通阶数 | 4（butter, sosfiltfilt 零相位） | 兼顾选择性与稳定性 |
| 马氏触发阈值 | 正常集 5 折折外距离 p99 | 辅助判据；95/99.7 供敏感性 |
| 轴承判决置信度门槛 | 平衡 0.2（保守 0.3 / 灵敏 0.1） | 低置信标记用，逐文件置信度落盘可事后重算 |

### 12.3 转速先验的降级（设计立场，实测依据）

v2 把转速从"必需输入"降级为"可选记录"：

- **判据不依赖**：梳检、干扰防护、定位全部只用信号的周期结构与几何阶次，
  转速仅出现在"轴频谐波防护基准"与"频带窗"两处**软约束**（都用标称窗，
  不用实测值）；
- **转速自估仅记录**：`diagnose.estimate_rpm`（包络谱 1×fr 峰法）仍在运行，
  但第二批现场数据实测其 prominence 中位仅 2.0（< 阈值 5），回退率
  **92.6%**——现场信号的包络 1×fr 峰普遍不可用（强电机音主导）。这直接
  证成了 v1 依赖转速先验的结构性失败，也是 v2 设计的实测依据；
- **定位的副产品**：定位成功的梳反演 fr_hyp（窗内轴频），在故障文件上是
  比 1×fr 峰法更可靠的转速证据；
- **边缘行为的代价**：真转速显著出窗时，真实故障梳被挤到空档 → 判
  "未定位"而非误判（保守退化，见 11.3）。

### 12.4 方法局限与本库边界

- **变转速工况**：特征频率正比于 fr，转速波动会使谱线模糊。规范做法是
  阶次跟踪（角域重采样）后再做包络分析——统一包按合并决议不实现（无变速
  场景，design.md D22）；
- **分布式故障**（磨损、均匀点蚀）：无离散冲击与谐波族，梳检先天不适合，
  应以 RMS 趋势 + 马氏基线/ML 检测为主；
- **非轴承周期源**：盲梳检确认的是"周期性冲击存在"，不等于轴承独有——
  齿轮啮合、皮带、电磁都可能成梳。干扰防护覆盖轴频族与工频，其余靠
  "未定位"兜底 + 人工复听（验收报告中的 110 条未定位清单即此类）；
- **多故障耦合**：两处缺陷同时存在时谐波族交叠，梳的去重与定位排序可靠性
  下降，必须人工读谱；
- **复合工况干扰**（齿轮箱内轴承）：齿轮啮合边带与轴承特征频率纠缠，常需
  先做信号分离（如 MED、时频滤波）；
- 低信噪比下本库策略是"宁可漏报（判正常/未定位并提示），不可误报部位"——
  体现在低 SNR 端到端测试的验收标准中；
- **马氏辅助判据的重尾塌陷**：健康总体冲击性特征重尾时，p99 触发阈值会
  非常保守（检出率低）。可选缓解（未内置，留后续评估）：特征 log/秩变换、
  robust 协方差、分位数触发（见 baseline.py docstring 与
  analysis/reports/audio_assets/音频资产库评测报告.md §9）。

## 13. 机器学习方法：特征工程与模型训练

本章对应 `bearing_unified/ml/` 子包（`ml-dataset` / `ml-train` / `predict`
命令）。与传统 DSP 主线（第 4~11 章）的关系：**DSP 把物理判据写死在代码
里，机器学习把同一批物理量作为特征交给分类器学出判据**。两者共享特征提取
的核心（时域指标、包络谱、Kurtogram、盲梳检结构化输出），因此模型的行为
可以用第 10、11 章的物理知识解释与复核。

### 13.1 特征工程：六组特征的设计依据

任务：一段窗口信号 → 51 维特征向量 → **两级分类**（先正常/异常检测，异常
再分三类故障，见 13.3 节；`--arch flat` 可选单级 4 分类做 A/B 对比）。

| 组 | 特征 | 维数 | 设计依据 |
|---|---|---|---|
| T1 时域指标 | 第 4 章 9 项（rms/peak/p2p 做 log1p 变换） | 9 | 有量纲项跨工况不可比，log 压缩量纲；无量纲项天然尺度不变 |
| T2 物理判别 | 三候选特征频率（BPFO/BPFI/BSF）× 5 次谐波的包络谱局部突出度 | 15 | 与 matcher 同源（第 11.3 节），严格尺度不变，是判别力核心（glm 四候选 20 维 → 统一包三候选 15 维） |
| T3 谱峭度 | Kurtogram 最佳峭度、选中频带中心/宽度（归一化）、各层最大峭度 | 6 | 冲击存在性及所在频带位置（第 8 章） |
| T4 频谱形态 | 8 分频带能量占比、谱重心、谱熵、谱平坦度 | 11 | 能量分布的"形状"描述子，不依赖转速/轴承参数 |
| T5 包络谱形态 | 包络谱熵、主峰局部突出度 | 2 | 调制结构复杂度与强度 |
| T6 盲梳检结构化 | 净梳数、最强梳得分、是否落带、干扰标记数、3 类定位置信度、未定位标记 | 8 | 与 v2 DSP 同源的"软判决"（第 10、11 章）；**不依赖转速**（频带由标称窗×几何现算），是 T2 失效场景（转速不可锚定）下的物理证据通道 |

维度口径：默认（T2+T6 全开）51；`--no-comb` 43；`--no-physical`（去 T2）
36；两者皆去 28。

设计要点：

- **三轨制**：T2+T3 是"物理轨"（依赖转速+几何，判别力强）、T1+T4+T5 是
  "统计轨"（工况无关）、T6 是"结构轨"（依赖几何不依赖转速）。`--no-physical`
  剔除 T2 检验"不看特征频率能判多准"；`--no-comb` 剔除 T6 检验梳特征的增量；
- **尺度不变优先**：T2–T6 按构造尺度不变（测试断言了放大 100 倍后特征不变），
  T1 有量纲项以 log1p 压缩；
- **T6 消融结论（小规模仿真）**：全特征路线有/无 T6 一致（T2 已饱和）；
  盲路线（去 T2）有 T6 时 LOSO 端到端 0.969 vs 无 T6 时 0.875——T6 在
  转速不可锚定场景贡献约 9 个百分点跨工况精度，默认保留。

### 13.2 数据增强与防泄漏分组

仿真数据集（`ml/dataset.make_sim_dataset`）的生成协议：

- 每条**基录音**独立抽取增强参数——转速（FIELD7 恒速窗 1100/1133/1167/
  1200 rpm 四点轮转，保证 LOSO 每档都有样本）、SNR（−5~15 dB 均匀）、
  共振频率（1~3 kHz，覆盖本台架实测 1–1.5 kHz 共振区）、滑移（0.5~2%）、
  随机种子；
- 每条基录音是一段连续长信号，切成若干**窗**（默认 1 s/窗），同源窗共享同一
  个 `group` id；
- 4 类（normal/BPFO/BPFI/BSF）× 15 基 × 8 窗 = 480 样本（默认规模）。

**为什么必须分组**：同一条基录音的两个窗共享同一噪声实现与同一套增强参数，
统计上强相关。若随机划分，训练集和测试集出现"近亲"，准确率虚高——这是仿真
训练最常见、也最隐蔽的作弊。所有交叉验证（GroupKFold）与 LOSO 都按 group
切分，保证两侧来自完全独立的信号实现。（测试
`test_group_leakage_structure` 断言了分组结构。）

### 13.3 分类架构：两级层次分类（默认落地架构）

```
Stage 1 检测器   normal vs abnormal 二分类
    │ p_abnormal < threshold → 判正常，结束
    ▼ 判异常
Stage 2 分类器   BPFO/BPFI/BSF 三分类（仅故障样本训练）
    → 故障类型 + 条件概率 P(fault|abnormal)
```

联合置信度 = p_abnormal × P(fault|abnormal)，联合分布对四类归一。

为什么两级比单级 4 分类更适合落地：

1. **报警与定位是两个业务决策**：现场首先关心"有没有故障"（停机决策），再关
   心"什么故障"（检修方案）。两级把两个决策拆开，各自的置信度与阈值独立可调；
2. **漏报/误报可按代价优化**：Stage1 阈值降低→报警更灵敏（漏报减少、误报增
   多），反之保守。训练报告给出 0.3/0.5/0.7 三个阈值工作点的漏报率/误报率，
   现场按业务代价选择；单级模型没有这个自由度；
3. **故障样本稀缺时更稳**：Stage2 只学"故障之间"的边界（三类），不承担"正常
   vs 故障"的边界，小样本下更可靠；
4. **与 v2 DSP 同构**：DSP 判决天然两级（先判有无梳特征，再判部位），两法
   对比语义对齐。

模型包带 `arch` 字段（`two_stage`/`flat`），推理端自动分派；旧版无 arch 字段
的模型包按 flat 兼容。预测时 `--threshold` 覆盖默认阈值。

### 13.4 Stage1 后端：监督式与新奇检测

Stage1 有两种可切换后端（`--stage1 supervised|novelty`，默认 supervised）：

- **监督式（默认）**：normal vs abnormal 标签二值化后走完整监督管线
  （四分类器 GroupKFold 对比 → macro-F1 选优 → 小网格调参 → 全量重拟合；
  LinearSVM/RBF-SVM 经 sigmoid 校准）。需要"有故障标注"的前提；
- **新奇检测（`NoveltyDetector`，kimi 移植项）**：**只训健康样本**的
  EllipticEnvelope（稳健马氏距离思路），覆盖"现场无故障标注"场景——
  部署初期只有健康录音可用时，检测器依然可用。两个 kimi 侧的实测教训
  已固化在设计里（train.py docstring）：
  - **IsolationForest 检出率会塌缩为 0**：IF 的分裂界由训练数据 min/max
    决定、不随极端程度外推，健康样本数或网格配置稍变即可能把全部故障判
    为正常；EllipticEnvelope 基于马氏距离，同批实验全配置检出率 1.0。
    IF 后端仅作对照保留、默认不用；
  - **检测级只用少量冲击性特征**：全特征维下健康样本有近零方差方向，
    标准化后高维稀疏、小样本协方差病态（EE 的 MCD 要求 n≫p）。检测器
    默认只用 4 维（t1_kurtosis / t1_crest_factor / t1_clearance_factor /
    t5_env_peak_prom）；
  - **兼容 sklearn 的标签编码**：`cross_val_predict` 对分类 y 做
    LabelEncoder（0/1），检测器内部对 {normal, abnormal} 与 {0,1} 两种
    标签形式都识别（sorted({abnormal, normal}) → normal=1 为确定性映射）；
- **概率口径**：新奇检测输出的是启发式伪概率（以健康样本 decision_function
  的中位数/标准差做 z 化后过 logistic），不是统计意义上的校准概率；阈值
  工作点在该单调轴上仍然可操作。评估协议与监督后端完全一致（GroupKFold/
  LOSO/工作点扫描），且**各折训练集只用其健康样本拟合检测器**（协议要求，
  测试覆盖）。

### 13.5 评估协议：三层验证

1. **GroupKFold(5) 防泄漏交叉验证**：四分类器（LinearSVM/RBF-SVM/随机森林/
   HistGradientBoosting）用默认参数同台对比，macro-F1 选优；
2. **小网格调参**：胜者在同一 GroupKFold 内做 GridSearch（小网格，f1_macro），
   最优超参在全量数据重拟合；
3. **LOSO 留一转速**：依次留出一档转速全部样本做测试、其余转速训练。特征频
   率随转速线性变化（第 3 章），该协议检验模型学到的是"故障模式"还是"某个
   工况的指纹"——跨工况部署可信度的下界估计。

指标：accuracy、macro-F1（类别不均衡时更公平）、每类 precision/recall/F1、
混淆矩阵。两级架构额外输出（`hierarchical_cv_report`）：

- **Stage1 分级指标**：二分类准确率/F1，以及**漏报率**（故障被判正常）与
  **误报率**（正常被判异常）分开统计——现场两者代价不对称，混在一个准确率
  里会掩盖关键风险；
- **阈值工作点扫描**：同一份 Stage1 交叉验证概率上比较 0.3/0.5/0.7 阈值的
  漏报/误报，供按业务策略选点；
- **端到端层次准确率**：normal 判对且（若故障）门控通过且类型判对才计对。

交叉验证指标一律用**未拟合的配置化估计器**（`make_estimator` 按选型结果重
建）做 `cross_val_predict`，而不是用全量重拟合的模型评自己训练过的数据。

### 13.6 概率输出与可解释性

- 所有分类器统一输出 `predict_proba`（LinearSVM/RBF-SVM 经 sigmoid 校准
  CalibratedClassifierCV），两级架构输出：p_abnormal、Stage2 条件概率、
  四类联合分布与联合置信度；
- 推理时列出该样本 |z| 最大的特征（经训练 scaler 标准化），例如 BPFO 样本
  的 top 特征几乎总是 `t2_BPFO_k1..k5`——模型判据与传统方法的谐波匹配判据
  一致，可被第 11 章的物理知识直接解释；
- `predict --compare` 在同一信号上并列运行 **v2 DSP**（统一包的"传统方法"
  是盲梳检流水线，不是 glm 的 matcher——它不依赖转速，对比不再需要提供
  转速/轴承），两法不一致时提示人工复核（不一致本身就是有价值的信息：
  可能是分布外样本）。

### 13.7 转速约定（推理端）

预测时 T2 物理特征组需要轴频。解析约定（`_resolve_shaft_freq`，docstring
写明）：**用户给定优先（--shaft-freq > --rpm/60），否则包络谱 1×fr 峰自估、
失败回退标称窗中点（如 1150 rpm）**。v2 DSP 与 T6 盲梳检特征均不依赖转速，
该约定只服务 T2——这与 12.3 节的"转速先验降级"立场一致。

### 13.8 何时值得升级到深度学习

| 场景 | 建议 |
|---|---|
| 样本少（<几千窗）、需可解释、多机型 | 手工特征 + 经典 ML（本方案） |
| 大量标注数据、变转速、多故障耦合、分布复杂 | 1D-CNN / 时频图 CNN 端到端 |
| 域差距大（仿真训练→实测部署） | 先考虑域随机化增强（本库已做一部分）与域适应，而非直接上深度模型 |

深度路线的代价：训练与推理成本高、需 GPU、判据黑箱化；收益主要在特征难手工
描述的场景。轴承单点故障的判据物理上明确（第 2、3 章），手工特征已携带主要
信息——这也是文献中"手工特征+经典 ML"长期是 CWRU 基准强基线的原因。

### 13.9 局限

- **仿真到实测的域差距**是本方案最大风险：真实轴承的故障形态（分布式磨损、
  多点缺陷）、背景（齿轮箱振动）与仿真有差距。缓解：`load_dataset_dir`
  支持混入真实标注数据重训；部署前务必用现场数据验证 LOSO；
- 概率校准依赖训练分布，分布外样本的概率未必可靠（两法不一致告警部分覆盖
  此风险）；
- 变转速工况仍需先做阶次跟踪（与第 12.4 节同）；
- 新奇检测后端的健康基线对**工况广度**敏感：留出转速的正常样本可能被误报
  （实测小规模 LOSO 中端到端 0.77，短板在留出档正常误报而非故障漏报）——
  部署时应尽量覆盖全部工况的健康样本再标定。
