# 设计文档（统一包）

日期：2026-09-23（阶段三定稿）。本文是统一包立项以来的设计决策存档，记录
"为什么这样做"；各方法的原理细节见 [principles.md](principles.md)。
以 glm `docs/design.md`（D1–D13）为底本迁移适配，并新增 D14+（v2 盲梳检
规则及其落地细节）。

## 需求与定位

- 交付物：统一 Python 包 `bearing_unified`（传统信号处理 + 经典 ML 的轴承
  故障诊断全流程）+ 原理文档 + notebook 示例；**自包含**，不依赖任何外部
  诊断包（两个姊妹项目已从仓库删除，历史见 git 仓库）；
- 方法范围（合并决议 Q6/Q9/Q10）：恒速场景；v2 盲梳检判别规则（先盲检
  存在性、再用理论定位）；ML 以 glm 两阶段监督式为骨架、kimi 新奇检测为
  Stage1 可选后端；评估协议统一 GroupKFold + LOSO + 阈值工作点 + 与
  v2 DSP `--compare`；
- 判别仅 3 类：外圈 BPFO / 内圈 BPFI / 滚珠 BSF（无保持架 FTF 判别）。

## 架构

```
loaders → preprocessing(去直流/去趋势/零相位带通)
        → kurtogram 选带 → 零相位解调 → 包络谱
        → combdet（盲梳检：显著峰梳扫 + 倒频谱互证 + 干扰防护）
        → localize（频带落入定位 + fr_hyp 补救 + 理论复核 ±4%）
        → baseline（马氏健康基线，辅助判据）
        → report（四联图 + 文本 + JSON）
        → ml/（T1–T6 特征 → 两级分类：Stage1 监督/新奇 → Stage2 三分类）
```

- 单向数据流，`diagnose.DiagnosisResult` 携带全部中间量（供报告与二次
  分析），不做任何隐藏状态；
- CLI 只是薄壳（`cli.py`），notebook/脚本/测试共用同一 API；
- 现场台架轴承 FIELD7 注册为内置默认轴承（`fault_freqs.py`，几何来自
  `labeled_dataset_4class/geometry.json`，打包场景有嵌入式副本兜底）。

## 迁移自 glm 的设计决策（D1–D13，经适配核对）

### D1 谐波匹配用"局部邻域中位数"做突出度基线

窄带噪声的包络谱随频率衰减，全局基线会让低频候选系统性虚高——开发中纯噪
声曾被稳定误判为故障（得分 1.0）。改局部基线（±max(16%, 10 谱线)）后正常
信号 9/9 正确。**统一包现状**：`matcher.py` 原样保留，并复用于梳检的显著峰
拾取与倒频谱互证的基线（`combdet.py`）。

### D2 整数倍混淆消解（BPFO = n×FTF 恒等式）

保持架故障的 k·FTF 谐波族覆盖 BPFO 全部谐波位置，纯 FTF 故障会给 BPFO 打
满分"继承"证据。规则：整数倍关系且小频率基频自身命中 → 大频率得分打 4 折。
**统一包现状**：matcher 保留该能力（FTF 不入判别，但理论复核/消歧逻辑同构，
测试 `test_ftf_vs_bpfo_deconfliction` 保留通过）。

### D3 包络峭度基线是 2.0 而非 3.0

带通信号的包络服从瑞利分布，未中心化 4 阶矩比基线为 2.0；实现与测试均按
2.0 标定，kurtogram 的"无冲击"阈值取 <4（含裕量）。**现状**：原样保留。

### D4 低信噪比策略：宁漏报不错报

判故障需 得分≥0.15 且 命中≥2 谐波；低 SNR 端到端测试的验收标准是"允许判
normal，不允许判错部位"。**统一包现状**：v2 继承并强化为三级诚实语义——
normal（无证据）/ bearing_unlocalized（有证据但无法定位）/ 部位（定位成功），
"无法定位"单列不强行归类（见 D16）。

### D5 Kurtogram 的两个工程修正

带通滤波起始振铃按 8·fs/B 截头；Hilbert（FFT 圆卷积）两端回绕伪影按 1%
截尾。两者都会虚增峭度导致选带错误。**现状**：原样保留。

### D6 报告必须可人工复核

自动判定永远伴随：原始指标、检出梳明细（f0/得分/命中/倒谱/干扰标记）、
定位频带表、三类置信度、包络谱谐波标注图、证据矛盾提示。诊断不是黑箱打分。
**现状**：`report.py` 四联图（时域/FFT/Kurtogram/包络谱+频带底纹+梳标注）
+ 中文文本 + JSON 三件套。

### D7 特征双轨制：物理特征与统计特征并行，物理特征为可选开关

T2（特征频率谐波突出度）与 matcher 同源；`--no-physical` 消融开关量化其
价值。**统一包现状**：T2 从四候选×5=20 维适配为三候选×5=15 维；并在双轨
之外新增第三轨 T6 盲梳检结构化特征（D19），三轨各有消融开关。

### D8 防泄漏分组是数据协议的一等公民

基录音（独立种子/独立增强参数）→ 切窗 → 同源窗共享 group；GroupKFold 与
LOSO 都按 group 切分。转速在基录音间确定性轮转，保证 LOSO 每档都有测试样
本。**统一包现状**：原样保留，转速网格改为 FIELD7 恒速窗
1100/1133/1167/1200 四点。

### D9 LOSO 作为跨工况泛化的主指标

GroupKFold 只证明同分布性能；LOSO（留一转速）检验"学的是故障模式还是工况
指纹"。报告同时给出两者，部署决策看 LOSO。**现状**：原样保留。

### D10 所有分类器统一输出概率

LinearSVM/RBF-SVM 经 CalibratedClassifierCV(sigmoid) 校准，分类器在
predict_proba 接口下同台可比。**现状**：原样保留；新奇检测后端输出启发式
伪概率（z 化 logistic，docstring 明确不是统计校准，见 D20）。

### D11 推理端强制参数一致性 + 两法交叉对比

物理特征模型预测时必须提供转速与轴承（特征维度校验兜底）；`--compare` 并列
传统方法结论，不一致即提示人工复核。**统一包适配**：传统方法对照换成 v2
DSP 盲梳检流水线（**它不依赖转速**——对比不再需要转速/轴承输入，比 glm
时代的 `--compare` 少一个硬性前提）；T2 的转速需求用"用户给定优先、否则
转速自估、回退标称窗中点"的约定兜底（`_resolve_shaft_freq`）。

### D12 仿真性能 ≠ 现场性能，诚实披露

文档与 CLI 输出明确：仿真上的满分只证明管线正确；真实性能需现场数据复验
（`load_dataset_dir` 支持混入真实标注数据重训）。**统一包现状**：原样保留；
阶段三的正式验收复测（1349 + 81 条真实数据）即按此纪律执行并公开门槛结果。

### D13 两级层次分类替换单级多分类（落地架构）

Stage1 检测器（阈值可调）→ Stage2 条件分类，联合置信度 = p_abnormal ×
P(fault|abnormal)。**统一包适配**：Stage2 从条件 4 分类改为**条件 3 分类**
（BPFO/BPFI/BSF，配合 D21）；标签集 {normal, BPFO, BPFI, BSF}。

## 新增决策（D14+，v2 时代）

### D14 v2 判别规则：先盲检存在性、再用理论定位（核心决策）

**决定**：判别从 v1 的"理论频率锚定匹配"（给定转速+几何→验证理论谱线）改为
v2 的"盲梳检存在性 + 频带落入定位"（先不问理论，先在包络谱上找周期族；
存在后用几何定位）。

**为什么（三条实测否决依据，来自两批真实数据评测）**：

1. **转速先验结构性不可靠**：现场无转速计，包络谱 1×fr 峰自估在第二批
   1349 条现场录音上回退率 92.6%（prominence 中位仅 2.0 < 阈值 5，电机
   音主导）。理论锚定的频率基准大面积缺失，v1 只能靠 1150 rpm 回退猜测；
2. **v1 触发级灵敏度塌陷**：马氏距离健康基线（p99 域内标定）在健康总体
   冲击性特征重尾（正常峭度 max 902）下协方差被尾部撑大，p99 异常检出率
   仅 9.3%（v1 评测报告 §4/§9 有完整量化）；
3. **理论匹配器无干扰防护**：轴频谐波族、50 Hz 工频族会被当成 BPFO 证据
   （实测正常文件 19638 的 50.26 Hz 梳若无防护即误报外圈）。

**v2 结果（同一批数据）**：正常误报 2.12% 持平、异常检出 32.4%（v1 的 3.5
倍）、轴承全体口径检出 48.8%（v1 复核级证据率 28% 的 1.7 倍），且这些数字
**不依赖任何转速输入**。

### D15 干扰防护：轴频族 + 工频梳显式标记排除

**决定**：确认的梳若满足 (a) 下探后基频 <20 Hz（low_f0，轴频族兜底）、
(b) f0 ≈ k×fr_nominal（轴频谐波）、(c) f0 ≈ 50.0 Hz（工频），打
`suspected_interference` 标记并从轴承判决排除（仍记录并统计）。

**为什么**：
- 实测 17.1 Hz 轴频谐波族的子梳 34.2/51.3 Hz 会分别落入滚珠/外圈频带
  造成假定位——仅靠频带落入无法分辨，必须显式排除（a/b 就是为此设计）；
- 工频 50 Hz 恰落在外圈频带 47.3–51.6 Hz 内，是经典误报源；
- **容差教训**：工频防护最初取 1.5 谱线容差，在短窗（ML 的 1–2 s 特征窗，
  df=0.5–1 Hz）下形成 ±0.75–1.5 Hz 的宽区，把真外圈梳（49.42 Hz，距
  50 Hz 仅 0.58 Hz）误吞——工频是精确频率，容差只覆盖谱分辨率即可，故设
  **0.4 Hz 硬上限**（`combdet.MAINS_TOL_MAX_HZ`；50.2 Hz 处的真外圈仍会
  被误标，属固有歧义，按保守处理）。

### D16 频带落入定位与"未定位"诚实语义

**决定**：定位用频带落入法（转速窗×几何导出四个互不重叠频带）+ 空档
fr_hyp 补救 + 理论复核；仍无解判「轴承特征存在但无法定位」
（bearing_unlocalized），**单列统计、不强行归类**。

**为什么**：盲梳检确认的是"周期性冲击存在"，不等于"轴承某部位故障"——
实测中存在出窗转速（fr≈17.97 Hz 的 46.32 Hz 外圈、~21 Hz 源、45 Hz 源）
与其他周期振源。强行归类会把这些全变成误报；单列后它们成为可人工复听、
可统计归因的透明集合（1349 条评测中未定位 89 条，含清单与梳基频分布图）。
频带表函数化（`localize.class_bands`）而非硬编码，换几何/转速窗即重算，
从根本上杜绝"表与几何不一致"的失效模式。

### D17 理论复核容差 ±4%（准入与谐波窗一致）

**决定**：定位的理论复核分两级——准入容差 ±4%（fr_hyp 夹取到轴频窗后理论
频率与 f0 的偏差）与谐波搜索窗 ±4%（matcher 的 `tol_rel` 参数化，默认仍
±2% 供梳检使用）。

**为什么**：现场真实转速会略出标称窗（实测 fr≈17.97 Hz 的外圈故障
46.32 Hz，BPFO 计算值 47.27 偏差 2.05%）。±2% 时该梳的理论复核必然失败、
被丢进"未定位"；±4% 把它正确纳入（统一包 1349 条评测中，21 条原型未定位
样本由此正确定位，反向移动 0 条）。±4% 也覆盖了滑移 1–2% 与转速窗边缘的
联合不确定度。否决依据：原型 v2（±2% 复核窗）对照实验直接量化。

### D18 梳检的两条防伪造规则（±1% 同族吸收 + 最低命中 k≤2）

**决定**：(a) 同族吸收容差 ±1%（`combdet.ABSORB_TOL_REL`），不用 matcher
的 ±2%；(b) 梳确认要求最低命中谐波 k ≤ 2（基频或 2 次）。

**为什么（均为开发期踩过的真坑，测试已固化）**：
- (a) ±2% 吸收会把相邻 ~2% 的**异族**强峰误并——SKF6205 内圈案例中，伪梳
  33.08 Hz 把真梳 162.3 Hz（BPFI）当"5 次谐波"吸收，真故障漏检。同族判
  定收紧到滑差量级（±1%）：真族分裂的代价仅是良性重复梳，异族误并的代价
  是真梳漏检，两害相权取前者；
- (b) 错误基频的高次谐波窗（±2% 相对窗随 k 线性展宽）会扫到不相干强峰拼
  成假族（上述 33.08 伪梳的全部命中恰在 k=4/5）。真族的基频或 2 次谐波几
  乎总是命中，"最低命中 k≤2"以零真伤代价拒绝此类伪梳。

### D19 T6 盲梳检结构化特征组（ML 第三轨）

**决定**：把 combdet/localize 的结构化输出做成独立 ML 特征组（8 维：净梳数、
最强梳得分、是否落带、干扰标记数、3 类定位置信度、未定位标记），默认启用，
消融开关 `--no-comb`。

**为什么**：T2 物理特征依赖转速锚定，转速不可锚定时（现场常态，见 D14）
物理轨失效。T6 依赖几何但不依赖转速，是盲路线下的物理证据通道。**消融
证据**：小规模仿真上全特征路线有/无 T6 一致（T2 饱和），盲路线（去 T2）
有 T6 时 LOSO 端到端 0.969 vs 无 T6 时 0.875——保留默认开启。特征尺度
不变性有测试断言（放大 100 倍不变）。

### D20 Stage1 新奇检测后端（EllipticEnvelope，只训健康样本）

**决定**：Stage1 增加 `novelty` 后端（`NoveltyDetector`），默认仍为
supervised；IF 后端仅对照保留、默认不用；检测级特征只用 4 维冲击性子集。

**为什么（kimi 侧两条实测教训，train.py docstring 全文记录）**：
1. IsolationForest 的分裂界由训练数据 min/max 决定、不随极端程度外推，
   健康样本数或网格配置稍变即可能把全部故障判为正常（**检出率塌缩为 0**）；
   EllipticEnvelope 基于稳健马氏距离，同批实验全配置检出率 1.0；
2. 全特征维下健康样本有近零方差方向，标准化后高维稀疏、小样本协方差病态
   （EE 的 MCD 要求 n≫p）——检测级只用 t1_kurtosis / t1_crest_factor /
   t1_clearance_factor / t5_env_peak_prom 4 维。
另外两条工程细节：评估协议兼容 sklearn 的 LabelEncoder（cross_val_predict
对分类 y 编码为 0/1，检测器对 {normal, abnormal} 与 {0,1} 两种标签形式都
识别）；各折训练集只用其健康样本拟合（防泄漏协议要求，测试覆盖）。
已知短板：留出工况的正常样本可能误报（小规模 LOSO 端到端 0.77，短板在
留出档正常误报而非故障漏报）——部署时应覆盖全部工况的健康样本再标定。

### D21 判别仅 3 类：无保持架 FTF

**决定**：判别类别 = {normal, BPFO, BPFI, BSF}（滚珠 2×BSF 主峰带归入滚珠）。
FTF 的特征频率计算与 matcher 消歧能力保留，但不参与判别与 ML 标签集。

**为什么**：保持架谱线弱、滑移大，且与 BPFO 存在恒等混淆（BPFO=n×FTF，
保持架故障的谐波族天然覆盖外圈证据位）；第一批 81 条评测中 FTF/cage 判决
统一计为"其他"（计错），强行判别弊大于利（合并评审 §6.2 原案）。减少一类
也使 Stage2 的分类面更简单。

### D22 不做变速/阶次跟踪（Q6 决议维持）

**决定**：不实现阶次分析、CWT、变速仿真。恒速下阶次谱≈频率归一化，价值
有限；变速需求出现时，kimi 包的 order_analysis/timefreq 源码可直接捡回。
v2 盲梳检对标称转速窗外的转速漂移是保守退化的（出窗→未定位而非误判，
见 D16），在"无变速场景"的评审口径下可接受。

## 验证（当前状态）

- **单元测试 176 项全绿**（~150 s）：物理真值（高斯峭度、CWRU 频率、SNR
  定量、加载器往返）、v2 端到端（FIELD7 三类×双 SNR 检出+定位、健康 9/9
  零误报、未定位语义、马氏路径）、梳检/倒谱/干扰防护/频带表/定位/补救、
  预处理零相位、baseline 标定、ML（防泄漏分组、两阶段行为、序列化
  roundtrip、新奇后端协议/接口/集成、T6、CLI 冒烟）；
- **正式验收复测（阶段三，1349 + 81 条真实数据）**：见
  `analysis/reports/unified_acceptance/统一包验收报告.md`——门槛逐项对照
  （含 1 项未达标的诚实归因）；
- 报告 PNG 经视觉验收（四面板布局、中文渲染、Kurtogram 热图可辨）。
