# 设计文档（存档）

日期：2026-09-19（传统路线），2026-09-19 增补机器学习路线。本文是项目立项时
的设计决策存档，记录"为什么这样做"；各方法的原理细节见
[principles.md](principles.md)。

## 需求与定位

- 交付物：Python 项目（传统信号处理轴承故障诊断全流程）+ 深入原理文档
  + SKILL.md（AI 助手技能入口）；
- 方法范围：核心经典全流程——时域指标、FFT、Hilbert 包络解调、Kurtogram
  选带、倒频谱（辅助）、BPFO/BPFI/BSF/FTF 谐波匹配判别；
- 自包含：测试与演示基于内置仿真信号，完全离线可跑；另提供通用加载器
  （CSV/TXT/NPY/NPZ/MAT，CWRU 命名自动识别）。

## 架构：管道式标准库 + CLI + SKILL 入口

```
loaders → detrend → indicators ┐
                               ├→ kurtogram 选带 → bandpass → envelope_spectrum
                               │        → matcher（四候选谐波匹配）→ verdict
                               └→ report（PNG 四联图 + 文本 + JSON）
```

- 单向数据流，每个模块一个明确职责、可独立测试；
- `diagnose.py` 是唯一编排者，`DiagnosisResult` 携带全部中间量（供报告与二
  次分析），不做任何隐藏状态；
- CLI 只是薄壳（`cli.py`），技能/脚本/笔记本共用同一 API。

## 关键设计决策

### D1 谐波匹配用"局部邻域中位数"做突出度基线

窄带噪声的包络谱随频率衰减，全局基线会让低频候选（FTF/BSF 低次谐波）系统
性虚高——开发中纯噪声被稳定误判为 FTF/BSF（得分 1.0、命中 5 次）。改局部
基线（±max(16%, 10 谱线)）后 9/9 正常信号正确。这是包络谱判读的经典陷阱，
已写入原理文档 9.2 节。

### D2 整数倍混淆消解（BPFO = n×FTF 恒等式）

保持架故障的 k·FTF 谐波族覆盖 BPFO 全部谐波位置，纯 FTF 故障会给 BPFO 打出
满分"继承"证据。规则：整数倍关系且小频率基频自身命中 → 大频率得分打 4 折。
BPFO 故障在 1×FTF 无谱线，不受影响。

### D3 包络峭度基线是 2.0 而非 3.0

峭度≈3 是原始高斯信号的中心化峭度；带通信号的包络服从瑞利分布，未中心化
4 阶矩比（谱峭度族的估计量）基线为 2.0。实现与测试均按 2.0 标定，kurtogram
的"无冲击"阈值取 <4（含裕量）。

### D4 低信噪比策略：宁漏报不错报

判故障需 得分≥0.15 且 命中≥2 谐波；低 SNR 端到端测试的验收标准是"允许判
normal，不允许判错部位"。

### D5 Kurtogram 的两个工程修正

带通滤波起始振铃按 8·fs/B 截头；Hilbert（FFT 圆卷积）两端回绕伪影按 1% 截
尾。两者都会虚增峭度导致选带错误，开发中均踩过。

### D6 报告必须可人工复核

自动判定永远伴随：原始指标、各候选得分明细、包络谱谐波标注图、证据矛盾提
示（峭度 vs 判定不一致时）。诊断不是黑箱打分。

## 机器学习路线增补（D7~D12）

### D7 特征双轨制：物理特征与统计特征并行，物理特征为可选开关

T2（特征频率谐波突出度，20 维）复用 matcher 的窗口与局部基线逻辑——模型
学到的判据与传统方法的谐波匹配同源、可互相解释。`--no-physical` 消融开关
量化其价值：默认规模实测 LOSO 1.00 → 0.92（最差档 0.84）。

### D8 防泄漏分组是数据协议的一等公民

基录音（独立种子/独立增强参数）→ 切窗 → 同源窗共享 group；GroupKFold 与
LOSO 都按 group 切分。随机划分会让同源窗跨训练/测试，仿真数据准确率虚高
（最常见的作弊路径）。转速在基录音间确定性轮转，保证 LOSO 每档都有测试样本。

### D9 LOSO 作为跨工况泛化的主指标

GroupKFold 只证明同分布性能；LOSO（留一转速）检验"学的是故障模式还是工况
指纹"。报告同时给出两者，部署决策看 LOSO。

### D10 所有分类器统一输出概率

LinearSVM/RBF-SVM 经 CalibratedClassifierCV(sigmoid) 校准（sklearn 1.9 起
SVC(probability=True) 已弃用），四分类器在 predict_proba 接口下同台可比。

### D11 推理端强制参数一致性 + 两法交叉对比

物理特征模型预测时必须提供转速与轴承（特征维度校验兜底）；`--compare`
并列传统方法结论，不一致即提示人工复核——分布外样本的重要信号。

### D12 仿真性能 ≠ 现场性能，诚实披露

文档与 CLI 输出明确：仿真上的满分只证明管线正确；真实性能需现场数据复验
（`load_dataset_dir` 支持混入真实标注数据重训）。

### D13 两级层次分类替换单级 5 分类（落地架构）

Stage1 检测器（normal vs abnormal，阈值可调）→ Stage2 四类故障分类（仅故障
样本训练，条件概率），联合置信度 = p_abnormal × P(fault|abnormal)。理由：
报警与定位是两个业务决策，可分别优化；漏报/误报按代价独立调阈值；故障样本
稀缺时 Stage2 边界更简单。落地细节：

- 训练报告给出 0.3/0.5/0.7 阈值工作点的漏报率/误报率（同一份 Stage1 CV 概率
  上扫描，成本近零）；
- 交叉验证指标用未拟合的配置化估计器（make_estimator 重建）计算，避免全量
  重拟合模型自评训练数据；
- 模型包带 arch 字段，旧 flat 包自动兼容；`--arch flat` 保留单级做 A/B；
- 默认规模实测：Stage1 各工作点漏报/误报均 0，端到端与 LOSO 均 1.0；Stage1
  对比中 LinearSVM 因 sigmoid 校准在可分数据上退化（macroF1 0.57）被淘汰，
  选出 RBF-SVM——分类器对比机制的直接收益。
